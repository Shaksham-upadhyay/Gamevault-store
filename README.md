# GameVault

A fictional online game store landing page, built to practice HTML and CSS layout techniques like grids, hover effects, and a sticky navbar. This is a demo project for learning purposes, not a real store.

## Features
- Sticky navbar with links to each section
- Hero banner with a featured game
- Popular games grid with hover animation
- Browse-by-category grid
- Weekend deals section with discounted prices
- Coming soon section for upcoming releases
- Player testimonials
- Newsletter signup form (front-end only, no backend)
- Fully responsive layout using CSS Grid and Flexbox

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, hover transitions)

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser

No installation or build steps needed.
